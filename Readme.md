## 🖼️ Seam Carving

**Content-Aware Image Resizing using Graph Theory**

Implementation of the Seam Carving algorithm using a **Directed Acyclic Graph (DAG)** and shortest-path optimization.

- Dual-gradient energy map
- Image represented as a DAG
- Topological ordering + shortest path
- Optimal complexity: **O(H × W)**
- Comparison with Dijkstra
- Benchmark: approximately **15 ms/seam vs 85 ms/seam**

`Python` • `NumPy` • `OpenCV` • `Graph Theory` • `DAG` • `Dijkstra`
